## 2. Prioridad ALTA

### [x] A1. La carpeta de MyL devuelve HTTP 500 con datos inválidos
**Archivo:** [backend/carpeta/views.py:444](../backend/carpeta/views.py:444) (`collection_upsert`), [:511](../backend/carpeta/views.py:511) (`wishlist_toggle`), [:536](../backend/carpeta/views.py:536) (`wishlist_update`), [:606](../backend/carpeta/views.py:606) (`collection_bulk_import`).

Es el mismo patrón que el A1 del informe #2, pero en la carpeta: los valores del body se usan directo, sin validar tipo ni existencia.

| Petición | Respuesta |
|---|---|
| `POST carpeta/collection/upsert/` `{"card":"xyz","quantity":1}` | **500** |
| `POST carpeta/collection/upsert/` `{"card":99999999,"quantity":1}` | **500** |
| `POST carpeta/collection/upsert/` `{"card":11567,"quantity":"abc"}` | **500** |
| `POST carpeta/collection/upsert/` `{"card":11567,"quantity":-5}` | **500** |
| `POST carpeta/collection/bulk-import/` `{"text":12345}` | **500** |
| `POST carpeta/wishlist/toggle/` `{"card":"xyz"}` | **500** |
| `POST carpeta/wishlist/toggle/` `{"card":99999999}` | **500** |
| `POST carpeta/wishlist/toggle/` `{"card":11567,"desired_quantity":"abc"}` | **500** |
| `PATCH carpeta/wishlist/11567/` `{"desired_quantity":"abc"}` | **500** |

**Causas concretas:**
- `collection_upsert`: `CollectionEntry.objects.create(card_id=card_id, quantity=int(data.get("quantity", 1) or 1))` revienta con `ValueError` (texto) o `IntegrityError` (carta inexistente). Tampoco exige `quantity >= 0`.
- `collection_bulk_import`: `(request.data.get("text") or "").strip()` revienta con `AttributeError` si `text` no es texto.
- `wishlist_toggle` / `wishlist_update`: mismo problema con `card` y `desired_quantity`.

**Cambio:** validar con un serializer (`card` como `PrimaryKeyRelatedField`, `quantity`/`desired_quantity` como `IntegerField(min_value=...)`, `text` como `CharField`). **Ya existe la versión correcta en el mismo repo**: [backend/riftbound/views.py:1032](../backend/riftbound/views.py:1032) (`toggle`) y [:1051](../backend/riftbound/views.py:1051) (`set_quantity`) devuelven 400/404 en estos mismos casos; conviene copiar ese patrón.

**Aceptación:** los 9 casos de la tabla responden 400 (o 404 si la carta no existe) y nunca 500.
**Test:** agregar los 9 casos a un `backend/carpeta/tests_rule_gap.py`.

### [x] A2. `POST /api/decks/my/<id>/cover/` con `card_id` no numérico: HTTP 500
**Archivo:** [backend/decks/views.py:240](../backend/decks/views.py:240)

```
{"card_id": "xyz"}       -> 500 ValueError
{"card_id": 99999999}    -> 400 (correcto)
```

La línea `deck.entries.filter(card_id=card_id).exists()` recibe el valor sin convertir. Es el único resto del A1 anterior: al endpoint `entries/` se le agregó la conversión a entero, pero a `cover/` no.

**Cambio:** convertir con `int()` dentro de un `try` y responder 400, igual que en `deck_entry_view`.
**Aceptación:** `{"card_id":"xyz"}` responde 400.

### [x] A3. `POST /api/decks/import/` acepta cualquier cosa y crea un mazo vacío
**Archivo:** [backend/decks/views.py:428](../backend/decks/views.py:428) (`import_deck`)

```
{"data":"no soy un mazo"} -> 201 {"id":165,"name":"Mazo importado","imported_entries":0,"missing_myl_ids":[]}
```

Ni el cuerpo ni `entries` se validan: cualquier JSON crea un mazo llamado "Mazo importado" con 0 cartas. Un usuario que se equivoque de archivo llena su lista de mazos basura sin ningún aviso, y cualquiera puede crear mazos en masa con un `POST` vacío.

**Cambio:** exigir que `entries` exista y sea una lista con al menos una entrada válida; si no, responder 400 con un mensaje claro. Si el archivo es correcto pero ninguna carta coincide, responder 400 diciendo cuántas faltaron en vez de crear el mazo.
**Aceptación:** un JSON sin `entries` válidas responde 400 y no crea ningún mazo.

### [x] M6. El label de un snapshot acepta 300 caracteres con `max_length=100`
`POST /api/decks/my/<id>/snapshots/` con un label de 300 caracteres responde **201** y guarda los 300.

**Archivo:** [backend/decks/models.py:76](../backend/decks/models.py:76) (`label = models.CharField(max_length=100)`) y [decks/views.py:330](../backend/decks/views.py:330).
